3.3 列表和元祖使用

一、什么是列表和元组

1. 列表（List）

列表是Python中最常用的数据结构之一，是一个有序的、可变的集合，可以存储任意类型的元素。

特点

  • 使用方括号[]定义
  • 元素之间用逗号分隔
  • 可变性：列表中的元素可以随时修改、添加或删除
  • 有序性：元素按照插入顺序排列，可以通过索引访问
  • 异构性：可以包含不同类型的元素
  • 动态性：长度可变，可以随时增删元素

创建方式

# 创建列表
list1 = []                          # 空列表
list2 = [1, 2, 3]                   # 数字列表
list3 = ['a', 'b', 'c']             # 字符串列表
list4 = [1, 'hello', 3.14, True]    # 混合类型
list5 = list('Python')              # 从字符串创建
list6 = [x for x in range(5)]       # 列表推导式

2. 元组（Tuple）

元组是Python中的另一种数据结构，是一个有序的、不可变的集合，可以存储任意类型的元素。

特点

  • 使用圆括号()定义
  • 元素之间用逗号分隔
  • 不可变性：元组一旦创建，其元素不能修改、添加或删除
  • 有序性：元素按照插入顺序排列，可以通过索引访问
  • 异构性：可以包含不同类型的元素
  • 静态性：长度固定，不能增删元素

创建方式

# 创建元组
tuple1 = ()                          # 空元组
tuple2 = (1, 2, 3)                   # 数字元组
tuple3 = ('a', 'b', 'c')             # 字符串元组
tuple4 = (1,)                        # 单元素元组（注意逗号）
tuple5 = 1, 2, 3                     # 不用括号也可以
tuple6 = tuple('Python')             # 从字符串创建

⚠️ 单元素元组的陷阱

# 错误：这不是元组，是括号表达式
not_tuple = (1)
print(type(not_tuple))  # 

# 正确：单元素元组需要逗号
is_tuple = (1,)
print(type(is_tuple))   #

二、列表的常用方法

1. 添加元素

方法 描述 示例
append(x)在列表末尾添加单个元素list.append(4)
insert(i, x)在指定位置插入元素list.insert(1, 'new')
extend(iterable)在末尾添加可迭代对象的所有元素list.extend([5, 6])
+ 运算符连接两个列表new_list = list1 + list2
 
fruits = ['apple', 'banana']
fruits.append('cherry')           # ['apple', 'banana', 'cherry']
fruits.insert(1, 'orange')        # ['apple', 'orange', 'banana', 'cherry']
fruits.extend(['grape', 'mango']) # ['apple', 'orange', 'banana', 'cherry', 'grape', 'mango']

# 注意：append和extend的区别
list1 = [1, 2, 3]
list2 = [4, 5]
list1.append(list2)  # [1, 2, 3, [4, 5]] - 添加整个列表
list1.extend(list2)  # [1, 2, 3, [4, 5], 4, 5] - 展开添加

2. 删除元素

方法 描述 示例
remove(x)删除第一个匹配的元素list.remove('a')
pop([i])删除并返回指定位置的元素list.pop(0)
clear()清空列表中的所有元素list.clear()
del 语句删除指定位置的元素或整个列表del list[0]
 
fruits = ['apple', 'banana', 'cherry', 'banana']
fruits.remove('banana')  # 删除第一个'banana'
fruits.pop(0)           # 删除并返回'apple'
fruits.pop()            # 删除最后一个元素
fruits.clear()          # 清空列表

3. 查找和访问元素

fruits = ['apple', 'banana', 'cherry']

# 索引访问
print(fruits[0])     # 'apple'
print(fruits[-1])    # 'cherry'

# 切片
print(fruits[1:3])   # ['banana', 'cherry']

# 查找方法
print(fruits.index('banana'))  # 1
print(fruits.count('apple'))   # 1

# 内置函数
print(len(fruits))    # 3
print(max(fruits))    # 'cherry'
print(min(fruits))    # 'apple'

4. 排序和反转

numbers = [3, 1, 4, 1, 5, 9]

# 原地排序
numbers.sort()                # [1, 1, 3, 4, 5, 9]
numbers.sort(reverse=True)    # [9, 5, 4, 3, 1, 1]

# 反转
numbers.reverse()              # [1, 1, 3, 4, 5, 9]

# 返回新列表（不修改原列表）
sorted_numbers = sorted(numbers)       # [1, 1, 3, 4, 5, 9]
reversed_numbers = list(reversed(numbers))  # [9, 5, 4, 3, 1, 1]

三、列表推导式

列表推导式是创建列表的简洁方式。

基本语法

[expression for item in iterable if condition]

示例

# 创建平方数列表
squares = [x**2 for x in range(10)]
# [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件的列表推导式
even_squares = [x**2 for x in range(10) if x % 2 == 0]
# [0, 4, 16, 36, 64]

# 嵌套列表推导式
matrix = [[i*j for j in range(3)] for i in range(3)]
# [[0, 0, 0], [0, 1, 2], [0, 2, 4]]

四、元组的常用方法

由于元组是不可变的，其方法相对较少，主要集中在查询和访问方面。

1. 查找和访问元素

tup = ('a', 'b', 'c', 'a')

# 索引和切片（与列表相同）
print(tup[0])      # 'a'
print(tup[1:3])    # ('b', 'c')

# 查找方法
print(tup.index('b'))  # 1
print(tup.count('a'))  # 2

# 内置函数
print(len(tup))    # 4
print(max(tup))    # 'c'
print(min(tup))    # 'a'

2. 元组解包

# 基本解包
a, b, c = (1, 2, 3)
print(a, b, c)  # 1 2 3

# 使用*解包
first, *rest, last = (1, 2, 3, 4, 5)
print(first)  # 1
print(rest)   # [2, 3, 4]
print(last)   # 5

五、列表和元组的区别

特性 列表（List） 元组（Tuple）
可变性 可变：可以修改、添加、删除元素 不可变：创建后不能修改元素
语法 使用方括号 [] 使用圆括号 ()
性能 创建和修改较慢，占用内存较多 创建和访问较快，占用内存较少
方法 丰富的方法集（增删改查） 有限的方法集（主要是查询）
用途 适合需要修改的数据集合 适合固定的数据集合
哈希 不可哈希，不能作为字典的键 可哈希，可以作为字典的键
内存 动态分配内存，需要额外空间 静态分配内存，更节省空间

性能差异

import sys

list_example = [1, 2, 3, 'a', 'b', 'c']
tuple_example = (1, 2, 3, 'a', 'b', 'c')

print(f"列表大小: {sys.getsizeof(list_example)} 字节")
print(f"元组大小: {sys.getsizeof(tuple_example)} 字节")

💡 性能建议

元组比列表有更好的性能表现，特别是在性能敏感的场景中。

六、列表和元组的使用场景

1. 使用列表的场景

  • 需要修改数据时：当数据集合需要频繁修改时
  • 动态数据集合：当数据集合的大小会变化时
  • 栈和队列实现：列表适合实现栈（append/pop）和队列
  • 临时数据存储：当数据只是临时使用，不需要长期保存时
  • 需要丰富操作时：当需要对数据集合进行排序、反转等操作时
# 示例：动态添加数据
shopping_list = []
shopping_list.append('milk')
shopping_list.append('bread')
shopping_list.append('eggs')
print(shopping_list)

2. 使用元组的场景

  • 固定数据集合：当数据集合创建后不需要修改时
  • 字典键：元组可以作为字典的键，而列表不能
  • 函数返回多值：函数返回多个值时通常使用元组
  • 数据保护：当需要确保数据不被意外修改时
  • 性能敏感场景：当性能是重要考虑因素时
  • 多线程编程：元组的不可变性使其在多线程环境中更安全
# 示例：函数返回多值
def get_user_info(user_id):
    # 模拟数据库查询
    return ('Alice', 25, 'alice@example.com')

name, age, email = get_user_info(1)
print(f"{name}, {age}岁, {email}")

3. 混合使用场景

# 配置参数使用元组（不可变）
CONFIG = ('localhost', 8080, True)

# 动态数据使用列表（可变）
users = []

# 元组作为字典的键
coordinates = {}
coordinates[(0, 0)] = '起点'
coordinates[(1, 1)] = '终点'

七、常见操作总结

1. 索引和切片

# 正索引
seq = [0, 1, 2, 3, 4]
print(seq[0])   # 第一个元素
print(seq[-1])  # 最后一个元素

# 切片
print(seq[1:4])   # [1, 2, 3]
print(seq[:3])    # [0, 1, 2]
print(seq[2:])    # [2, 3, 4]
print(seq[::2])   # [0, 2, 4]（步长为2）

2. 序列运算符

# 拼接
list1 = [1, 2]
list2 = [3, 4]
print(list1 + list2)  # [1, 2, 3, 4]

# 重复
print(list1 * 3)  # [1, 2, 1, 2, 1, 2]

# 成员检查
print(2 in list1)   # True
print(5 in list1)   # False

3. 内置函数

seq = [3, 1, 4, 1, 5, 9]

print(len(seq))    # 6 - 长度
print(max(seq))    # 9 - 最大值
print(min(seq))    # 1 - 最小值
print(sum(seq))    # 23 - 求和
print(sorted(seq)) # [1, 1, 3, 4, 5, 9] - 排序

总结

列表和元组是Python中最基础的数据结构：

  • 列表：可变、灵活、方法丰富，适合需要修改的数据
  • 元组：不可变、高效、安全，适合固定的数据
  • 选择依据：根据是否需要修改、性能要求、使用场景来选择
  • 共同操作：索引、切片、序列运算符、内置函数

理解它们的区别和适用场景，能够帮助我们编写更高效、更安全的Python代码。
