4.2 循环语句

循环语句的基本概念

循环是编程中最基本也是最重要的控制结构之一，它允许代码重复执行，直到满足特定的条件为止。Python提供了两种主要的循环结构：for循环和while循环。

一、for循环

for循环是Python中最常用的循环结构，用于遍历任何序列（如列表、元组、字符串）或其他可迭代对象。

基本语法

for variable in sequence:
    # 循环体
    pass

基本用法

# 遍历列表
fruits = ['apple', 'banana', 'cherry']
for fruit in fruits:
    print(fruit)

# 遍历字符串
for char in "Python":
    print(char)

# 遍历范围
for i in range(5):
    print(i)  # 输出：0, 1, 2, 3, 4

通过序列索引迭代

fruits = ['apple', 'banana', 'cherry']
for index in range(len(fruits)):
    print(f"索引 {index}: {fruits[index]}")

使用enumerate()获取索引和值

fruits = ['apple', 'banana', 'cherry']
for index, fruit in enumerate(fruits):
    print(f"索引 {index}: {fruit}")

# 输出：
# 索引 0: apple
# 索引 1: banana
# 索引 2: cherry

💡 enumerate()的优势

使用enumerate()比使用range(len())更加Pythonic，代码更简洁易读。

二、while循环

while循环在条件为True时重复执行代码块，当条件变为False时停止。

基本语法

while condition:
    # 循环体
    pass

基本用法

# 计数器
count = 0
while count < 5:
    print(count)
    count += 1

# 输出：0, 1, 2, 3, 4

无限循环

# 注意：确保有退出条件
while True:
    user_input = input("输入'quit'退出：")
    if user_input == 'quit':
        break

⚠️ 避免无限循环

使用while循环时，务必确保循环条件最终会变为False，否则会造成无限循环。

三、循环控制语句

Python提供了三个循环控制语句：break、continue和pass，用于控制循环的执行流程。

1. break语句

break语句用于立即终止整个循环，跳出循环体。

# 查找列表中的第一个偶数
numbers = [1, 3, 5, 4, 7, 9]
for num in numbers:
    if num % 2 == 0:
        print(f"找到偶数：{num}")
        break

# 输出：找到偶数：4

2. continue语句

continue语句用于跳过当前循环的剩余语句，直接进入下一次循环。

# 打印奇数
for i in range(10):
    if i % 2 == 0:
        continue
    print(i)

# 输出：1, 3, 5, 7, 9

3. pass语句

pass是空语句，不做任何事情，一般用作占位符，保持程序结构的完整性。

# 占位符示例
for i in range(5):
    pass  # TODO: 稍后实现

四、循环的else语句

Python中的循环可以带有一个else子句，它在循环正常结束（即不是通过break跳出）时执行。

1. for...else语句

# 查找质数
for n in range(2, 10):
    for x in range(2, n):
        if n % x == 0:
            print(f"{n} 等于 {x} * {n//x}")
            break
    else:
        # 没有找到因数
        print(f"{n} 是质数")

2. while...else语句

count = 0
while count < 5:
    print(count)
    count += 1
else:
    print("循环正常结束")

💡 else语句的执行时机

else子句只在循环正常结束时执行，如果循环被break终止，则不会执行else子句。

五、列表推导式

列表推导式是Python中创建列表的简洁方式，它可以将for循环和if语句结合在一行代码中。

基本语法

[expression for item in iterable if condition]

基本用法

# 创建平方数列表
squares = [x**2 for x in range(10)]
print(squares)  # [0, 1, 4, 9, 16, 25, 36, 49, 64, 81]

# 带条件的列表推导式
even_squares = [x**2 for x in range(10) if x % 2 == 0]
print(even_squares)  # [0, 4, 16, 36, 64]

性能特点

  • 立即计算：列表推导式是Eager Loading，所有元素在创建时立即计算并存储在内存中
  • 适合场景：需要多次迭代、数据集较小、需要随机访问
  • 内存考虑：对于大数据集可能会消耗大量内存

六、生成器表达式

生成器表达式与列表推导式类似，但它使用圆括号而不是方括号，返回的是一个生成器对象。

基本语法

(expression for item in iterable if condition)

基本用法

# 生成器表达式
squares_gen = (x**2 for x in range(10))
print(squares_gen)  #  at 0x...>

# 遍历生成器
for square in squares_gen:
    print(square)

性能特点

  • 惰性计算：Lazy Loading，元素只在需要时才生成
  • 内存效率：占用内存少，适合大数据集
  • 单次使用：只能迭代一次，不能重复使用

列表推导式 vs 生成器表达式

特性 列表推导式 生成器表达式
语法[]()
计算方式立即计算惰性计算
内存使用存储所有元素按需生成
可重复使用可以多次迭代只能迭代一次
随机访问支持索引访问不支持
适用场景小数据集大数据集

七、循环的嵌套

Python允许在一个循环体内嵌套另一个循环，这称为循环的嵌套。

1. for循环嵌套

# 打印乘法表
for i in range(1, 10):
    for j in range(1, i + 1):
        print(f"{j}x{i}={i*j}", end=" ")
    print()

2. while循环嵌套

# 打印矩形
i = 0
while i < 5:
    j = 0
    while j < 10:
        print("*", end=" ")
        j += 1
    print()
    i += 1

八、循环的最佳实践

💡 使用enumerate()获取索引

# 推荐
for index, item in enumerate(items):
    print(index, item)

💡 使用zip()同时迭代多个序列

names = ['Alice', 'Bob', 'Charlie']
ages = [25, 30, 35]

for name, age in zip(names, ages):
    print(f"{name} is {age} years old")

💡 避免在循环中修改被迭代的对象

# 错误：在循环中修改列表
numbers = [1, 2, 3, 4, 5]
for num in numbers:
    if num % 2 == 0:
        numbers.remove(num)  # 可能导致跳过元素

# 正确：创建新列表或使用列表推导式
numbers = [1, 2, 3, 4, 5]
numbers = [num for num in numbers if num % 2 != 0]

九、循环的常见应用场景

1. 数据处理

# 计算列表平均值
numbers = [1, 2, 3, 4, 5]
total = 0
for num in numbers:
    total += num
average = total / len(numbers)
print(f"平均值：{average}")

2. 文件处理

# 逐行读取文件
with open('data.txt', 'r') as f:
    for line in f:
        print(line.strip())

3. 算法实现

# 冒泡排序
def bubble_sort(arr):
    n = len(arr)
    for i in range(n):
        for j in range(0, n-i-1):
            if arr[j] > arr[j+1]:
                arr[j], arr[j+1] = arr[j+1], arr[j]
    return arr

总结

本节介绍了Python的循环语句：

  • for循环：遍历序列或可迭代对象
  • while循环：基于条件的循环
  • 循环控制：break、continue、pass
  • 循环else子句：循环正常结束时执行
  • 列表推导式：简洁创建列表
  • 生成器表达式：惰性计算，节省内存
  • 循环嵌套：多重循环

掌握循环是编程的基础，合理使用循环可以简化代码，提高效率。
