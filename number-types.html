2.1 数字类型

数据类型概述

计算机是用来处理数字的机器，但Python可以处理多种数据类型：

  • 整数：可以精确处理非常大的整数
  • 浮点数：浮点数运算都有误差，如8-2.1≠5.9
  • 复数：由实部和虚部两部分组成的数
  • 字符串：以单引号或双引号括起来的任意字符
  • 布尔值：只有True和False两种类型
  • 空值：特殊值，用None表示

整数类型（int）

Python的整数类型可以精确处理非常大的数值，没有大小限制。

不同进制的表示

在Python中默认使用十进制，也可以使用其他进制：

  • 0b或0B：二进制
  • 0o或0O：八进制
  • 0x或0X：十六进制
# 不同进制的整数
a = 42        # 十进制
b = 0b101010  # 二进制 (42)
c = 0o52      # 八进制 (42)
d = 0x2A      # 十六进制 (42)

print(a, b, c, d)  # 42 42 42 42

💡 运算优先级

幂的优先级高于乘除，乘除的优先级高于加减

result = 2 + 3 * 4 ** 2
print(result)  # 50
# 计算顺序：4**2=16 → 3*16=48 → 2+48=50

浮点数类型（float）

浮点数表示实数，用float表示。

表示方法

  1. 直接写：1.23、3.14
  2. 科学计数法：1.23e9（e后面必须是整数）
a = 1.23
b = 3.14
c = 1.23e9  # 1230000000.0

print(a, b, c)

⚠️ 浮点数精度问题

# 浮点数运算的精度问题
print(0.1 + 0.2)  # 0.30000000000000004
print(8 - 2.1)    # 5.8999999999999995

# 使用round函数处理
print(round(0.1 + 0.2, 1))  # 0.3

math模块

import math

# 常用数学函数
print(math.sqrt(9))      # 3.0 - 平方根
print(math.pi)           # 3.141592653589793 - 圆周率
print(math.e)            # 2.718281828459045 - 欧拉数
print(math.sin(math.pi/2))  # 1.0 - 正弦
print(math.cos(0))       # 1.0 - 余弦
print(math.log(math.e))  # 1.0 - 自然对数
print(math.ceil(2.3))    # 3 - 向上取整
print(math.floor(2.7))   # 2 - 向下取整

random模块

import random

print(random.randint(1, 10))  # 1-10随机整数
print(random.uniform(0, 1))   # 0-1随机浮点数
print(random.random())        # 0.0-1.0随机浮点数

复数类型（complex）

复数由实部和虚部（j）组成。

a = 3 + 4j
b = complex(3, 4)

print(a)          # (3+4j)
print(a.real)     # 3.0 - 实部
print(a.imag)     # 4.0 - 虚部
print(a.conjugate())  # (3-4j) - 共轭复数

总结

本节介绍了Python的数字类型：

  • 整数：精确表示大整数，支持多种进制
  • 浮点数：注意精度问题
  • 复数：支持复数运算
  • 数学函数：内置函数、math模块、random模块
