1.2 Python运算符优先级和结合性

运算符优先级和结合性表格

Python中的运算符具有不同的优先级和结合性，理解它们对于编写正确的表达式至关重要。

优先级 运算符 描述 结合性
1(expressions...), [expressions...], {key: value...}, {expressions...}圆括号、列表、字典、集合表达式从左到右
2x[index], x[index:index], x(arguments...), x.attribute下标、切片、调用、属性引用从左到右
3await x等待表达式无
4**幂运算从右到左
5+x, -x, ~x正号、负号、按位取反无
6*, @, /, //, %乘、矩阵乘、除、整除、取模从左到右
7+, -加、减从左到右
8<<, >>左移、右移从左到右
9&按位与从左到右
10^按位异或从左到右
11|按位或从左到右
12in, not in, is, is not, <, <=, >, >=, !=, ==成员测试、身份测试、比较从左到右
13not x逻辑非无
14and逻辑与从左到右
15or逻辑或从左到右
16if-else条件表达式（三元运算符）从右到左
17lambdaLambda表达式无
18:=海象运算符（赋值表达式）从右到左

详细说明

优先级说明

  • 数字越小，优先级越高：优先级1的运算符最先执行，优先级18的运算符最后执行
  • 相同优先级的运算符：按照结合性规则执行

结合性说明

  • 从左到右：运算符从左向右计算，如 a + b + c 等价于 (a + b) + c
  • 从右到左：运算符从右向左计算，如 a ** b ** c 等价于 a ** (b ** c)
  • 无：运算符不支持组合，如 -a 不能写为 - -a

各优先级运算符详解

优先级4：幂运算

幂运算符 ** 具有右结合性，这意味着 2 ** 3 ** 2 等于 2 ** (3 ** 2) = 512，而不是 (2 ** 3) ** 2 = 64。

>>> 2 ** 3 ** 2
512
>>> (2 ** 3) ** 2
64

优先级6：乘法类运算符

包括乘 *、矩阵乘 @、除 /、整除 //、取模 %。

>>> 7 / 2      # 浮点数除法
3.5
>>> 7 // 2     # 整除
3
>>> 7 % 2      # 取模
1

优先级12-15：比较和逻辑运算符

比较运算符包括 ==、!=、<、> 等，逻辑运算符包括 not、and、or。

>>> 3 > 2 and 5 < 10
True
>>> not (3 > 2)
False
>>> True or False
True

实际应用示例

复杂表达式分析

# 示例1：理解优先级
result = 2 + 3 * 4
# 先算乘法：3 * 4 = 12
# 再算加法：2 + 12 = 14
print(result)  # 14

# 示例2：使用括号改变优先级
result = (2 + 3) * 4
# 先算括号内：2 + 3 = 5
# 再算乘法：5 * 4 = 20
print(result)  # 20

# 示例3：幂运算的右结合性
result = 2 ** 3 ** 2
# 等价于：2 ** (3 ** 2) = 2 ** 9 = 512
print(result)  # 512

# 示例4：链式比较
x = 10
result = 5 < x < 15  # 等价于：(5 < x) and (x < 15)
print(result)  # True

最佳实践和注意事项

💡 使用括号明确优先级

即使知道运算符的优先级，也建议使用括号使代码更清晰：

# 不推荐
result = 2 + 3 * 4 ** 2

# 推荐
result = 2 + (3 * (4 ** 2))

💡 链式比较的特殊处理

Python支持链式比较，这在其他语言中不常见：

x = 10
# Python中：5 < x < 15 等价于 (5 < x) and (x < 15)
print(5 < x < 15)  # True

💡 短路求值的利用

逻辑运算符 and 和 or 具有短路特性：

# and 短路：如果第一个为False，不计算第二个
False and print("不会执行")
True and print("会执行")  # 会执行

# or 短路：如果第一个为True，不计算第二个
True or print("不会执行")
False or print("会执行")  # 会执行

常见错误和陷阱

⚠️ 运算符优先级误解

# 错误理解
if True or False and False:
    print("会执行")  # 会执行，因为and优先级高于or

# 正确理解：等价于
if True or (False and False):
    print("会执行")

⚠️ 混淆is和==

# == 比较值
print(1 == True)  # True

# is 比较身份（内存地址）
print(1 is True)  # False

总结

本节介绍了Python运算符的优先级和结合性：

  • 优先级从1到18，数字越小优先级越高
  • 结合性决定相同优先级运算符的执行顺序
  • 幂运算具有右结合性，其他大多数运算符是左结合的
  • 逻辑运算符具有短路特性
  • 使用括号可以使代码更清晰，避免歧义

掌握运算符优先级和结合性，有助于编写正确、高效的Python代码。
