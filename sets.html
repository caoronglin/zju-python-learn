5.1 集合

一、集合的定义和特点

1. 集合的定义

集合（Set）是Python中的一种内置数据类型，它是一个无序的不重复元素序列。集合中的元素不会重复，并且可以进行交集、并集、差集等常见的集合操作。

2. 集合的特点

  • 无序性：集合中的元素没有固定的顺序，不支持索引和切片操作
  • 唯一性：集合中的元素不能重复，具有自动去重的功能
  • 可变性：集合是可变的，可以添加或删除元素（但元素本身必须是不可变的）
  • 元素类型：集合中的元素必须是不可变类型（如数字、字符串、元组等）

3. 集合的创建

# 使用花括号创建
set1 = {1, 2, 3, 4, 5}
set2 = {'a', 'b', 'c'}

# 使用set()函数创建
set3 = set([1, 2, 3, 4, 5])
set4 = set('Python')  # {'P', 'y', 't', 'h', 'o', 'n'}

# 空集合（注意：{}创建的是字典）
empty_set = set()
print(type(empty_set))  # 

# 自动去重
set5 = {1, 2, 2, 3, 3, 3}
print(set5)  # {1, 2, 3}

4. 不可变集合（frozenset）

Python还提供了不可变集合frozenset，一旦创建就不能修改。

# 创建不可变集合
fs = frozenset([1, 2, 3, 4, 5])
# fs.add(6)  # 报错：frozenset不支持添加或删除

# frozenset可以作为字典的键
dict_with_fs = {fs: 'value'}

二、集合的基本操作

1. 添加元素

add()方法

添加单个元素到集合中，如果元素已存在，则不进行任何操作。

fruits = {'apple', 'banana'}
fruits.add('cherry')
print(fruits)  # {'apple', 'banana', 'cherry'}

# 添加已存在的元素，不会报错，也不会改变集合
fruits.add('apple')
print(fruits)  # {'apple', 'banana', 'cherry'}

update()方法

添加多个元素，参数可以是列表、元组、字典等。

fruits = {'apple', 'banana'}
fruits.update(['cherry', 'grape'])
fruits.update(('orange', 'mango'))
print(fruits)
# {'apple', 'banana', 'cherry', 'grape', 'orange', 'mango'}

2. 移除元素

remove()方法

移除指定元素，如果元素不存在，则会发生错误。

fruits = {'apple', 'banana', 'cherry'}
fruits.remove('banana')
print(fruits)  # {'apple', 'cherry'}

# fruits.remove('orange')  # KeyError

discard()方法

移除指定元素，如果元素不存在，不会发生错误。

fruits = {'apple', 'banana', 'cherry'}
fruits.discard('banana')   # 正常删除
fruits.discard('orange')   # 不报错
print(fruits)  # {'apple', 'cherry'}

pop()方法

随机删除并返回集合中的一个元素。

fruits = {'apple', 'banana', 'cherry'}
item = fruits.pop()
print(f"删除了: {item}")
print(f"剩余: {fruits}")

3. 集合的其他基本操作

fruits = {'apple', 'banana', 'cherry'}

# 计算集合元素个数
print(len(fruits))  # 3

# 清空集合
fruits.clear()
print(fruits)  # set()

# 判断元素是否在集合中
fruits = {'apple', 'banana', 'cherry'}
print('apple' in fruits)   # True
print('orange' in fruits)  # False

三、集合的运算

1. 交集（Intersection）

返回两个集合中共同存在的元素。

set1 = {1, 2, 3, 4, 5}
set2 = {4, 5, 6, 7, 8}

# 使用 & 运算符
intersection = set1 & set2
print(intersection)  # {4, 5}

# 使用 intersection() 方法
intersection = set1.intersection(set2)
print(intersection)  # {4, 5}

2. 并集（Union）

返回两个集合中所有元素（去重）。

set1 = {1, 2, 3}
set2 = {3, 4, 5}

# 使用 | 运算符
union = set1 | set2
print(union)  # {1, 2, 3, 4, 5}

# 使用 union() 方法
union = set1.union(set2)
print(union)  # {1, 2, 3, 4, 5}

3. 差集（Difference）

返回在第一个集合中存在但不在第二个集合中的元素。

set1 = {1, 2, 3, 4, 5}
set2 = {4, 5, 6, 7, 8}

# 使用 - 运算符
difference = set1 - set2
print(difference)  # {1, 2, 3}

# 使用 difference() 方法
difference = set1.difference(set2)
print(difference)  # {1, 2, 3}

4. 对称差集（Symmetric Difference）

返回只在其中一个集合中存在的元素。

set1 = {1, 2, 3, 4}
set2 = {3, 4, 5, 6}

# 使用 ^ 运算符
symmetric_diff = set1 ^ set2
print(symmetric_diff)  # {1, 2, 5, 6}

# 使用 symmetric_difference() 方法
symmetric_diff = set1.symmetric_difference(set2)
print(symmetric_diff)  # {1, 2, 5, 6}

5. 子集和超集判断

set1 = {1, 2, 3}
set2 = {1, 2, 3, 4, 5}
set3 = {1, 2}

# issubset()：判断是否为子集
print(set3.issubset(set1))  # True
print(set1 <= set1)        # True

# issuperset()：判断是否为超集
print(set2.issuperset(set1))  # True
print(set1 >= set3)           # True

# isdisjoint()：判断是否没有交集
set4 = {6, 7, 8}
print(set1.isdisjoint(set4))  # True

四、集合推导式

集合推导式（Set Comprehension）是一种简洁的创建集合的方式。

基本语法

{expression for item in iterable if condition}

示例

# 基本集合推导式
squares = {x**2 for x in range(5)}
print(squares)  # {0, 1, 4, 9, 16}

# 带条件的集合推导式
even_squares = {x**2 for x in range(10) if x % 2 == 0}
print(even_squares)  # {0, 4, 16, 36, 64}

# 从列表创建集合（自动去重）
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
unique_numbers = {x for x in numbers}
print(unique_numbers)  # {1, 2, 3, 4}

集合推导式的特点

  • 自动去重：即使推导过程中产生重复元素，结果集合中也只会保留一个
  • 无序性：集合中的元素没有固定顺序
  • 元素要求：元素必须是可哈希的（不可变类型）

五、集合的应用场景

1. 去重

集合最常见的用途是去除列表或其他可迭代对象中的重复元素。

# 列表去重
numbers = [1, 2, 2, 3, 3, 3, 4, 4, 4, 4]
unique_numbers = list(set(numbers))
print(unique_numbers)  # [1, 2, 3, 4]（顺序可能不同）

2. 成员检测

集合提供了高效的成员检测操作，判断一个元素是否在集合中。

# 集合的成员检测性能优于列表
large_list = list(range(100000))
large_set = set(large_list)

import time

# 列表检测
start = time.time()
result = 99999 in large_list
list_time = time.time() - start

# 集合检测
start = time.time()
result = 99999 in large_set
set_time = time.time() - start

print(f"列表: {list_time:.6f}秒")
print(f"集合: {set_time:.6f}秒")
# 集合的检测速度远快于列表

3. 集合运算

集合支持并集、交集、差集等运算，这对于数据处理和逻辑操作非常有用。

# 找出两个列表中的共同元素
list1 = [1, 2, 3, 4, 5]
list2 = [4, 5, 6, 7, 8]
common = set(list1) & set(list2)
print(common)  # {4, 5}

六、集合与其他数据类型的比较

1. 集合与列表的比较

特性 集合（Set） 列表（List）
有序性 无序 有序
可重复性 元素唯一 元素可重复
索引访问 不支持 支持
成员检测 O(1) - 非常高效 O(n) - 较慢
内存使用 通常占用更多内存 相对节省内存
适用场景 去重、成员检测、集合运算 需要顺序访问、允许重复

七、集合的最佳实践

💡 何时使用集合

  • 需要去重时：当需要确保数据中没有重复元素时
  • 频繁进行成员检测时：集合的O(1)时间复杂度比列表的O(n)更高效
  • 需要进行集合运算时：当需要进行交集、并集、差集等数学运算时
  • 数据顺序不重要时：当数据的顺序不重要，只需要确保唯一性时

⚠️ 何时避免使用集合

  • 需要保持数据顺序时：集合是无序的，不能保持元素的插入顺序
  • 需要索引访问时：集合不支持索引和切片操作
  • 存储可变元素时：集合中的元素必须是不可变类型

💡 性能优化建议

  • 使用集合进行成员检测，对于大型数据集比列表快得多
  • 使用集合推导式简洁地创建集合
  • 考虑使用frozenset当需要不可变集合时

总结

Python集合是一种强大而灵活的数据结构：

  • 核心特性：无序性、唯一性、可变性（元素本身不可变）
  • 主要优势：高效的成员检测（O(1)）、自动去重、支持数学集合运算
  • 适用场景：去重、成员检测、集合运算、数据分析等
  • 局限性：无序、不支持索引、元素必须是不可变类型

合理使用集合可以大大提高代码的效率和可读性。
